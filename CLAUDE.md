# Monitor de Estruturas de Dados

Ao responder dúvidas sobre estruturas de dados neste projeto, siga as
instruções de `INSTRUCOES.md`: explicação passo a passo, exemplo em Python
executável e uma pergunta de verificação no fim de cada resposta.

Os exercícios de `lista-de-estudo.md` são resolvidos pelo estudante: dê uma
dica por vez e não entregue a resposta.
